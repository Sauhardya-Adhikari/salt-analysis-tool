# Salt Analysis CLI Tool 🧪

A comprehensive Python-based command-line tool designed to simulate and assist with laboratory qualitative salt analysis (cation and anion detection) tailored for practical workflows.

## Features
* **Preliminary Tests:** Guided physical appearance checks and dry heating/flame test navigations.
* **Group Separation Logic:** Systematic step-by-step identification for cation groups.
* **Robust Exception Handling:** Prevents crashes from invalid inputs using structured control loops.

## How to Run
1. Ensure you have Python installed on your system.
2. Download or clone this repository.
3. Open your terminal in the project directory and run:
   ```bash
   python Salt_Analysis_CLI_Tool.py

Tech Stack
* Language: Python
* Paradigm: Procedural control flow with nested input loops and exception handling.
